SupaPlay API Docs + Live Tester

Build episode lists from an Anikoto slug

This page documents your SupaPlay Series API. It shows how the endpoint works, how the JSON response is structured, and lets you test any slug directly from the browser.

Test API Read Docs

Endpoint

Fetch series data and episodes using only the anime slug.

GET /api/series/:slug

Example

Example request for Dr. Stone: Stone Wars.

/api/series/dr-stone-stone-wars-yvphy

Player URLs

MegaPlay links are rewritten to SupaPlay links.

https://supaplay.fun/stream/s-2/{embed_id}/sub

How the API works

The API first uses the fast method. If that fails, it automatically switches to the slower fallback.

1. Fetch Anikoto watch page:
/watch/{slug}/ep-1
2. Extract the internal series ID:
#watch-main[data-id]
3. Try fast source:
https://anikotoapi.site/series/{series_id}
4. If fast source fails, use slow fallback:
Anikoto AJAX / server resolving method
5. Return clean JSON with:
anime, episodes, watch, and embed_url

Response shape

{
  "success": true,
  "data": {
    "slug": "dr-stone-stone-wars-yvphy",
    "series_id": 5781,
    "watch_url": "https://anikototv.to/watch/dr-stone-stone-wars-yvphy/ep-1",
    "source": "anikotoapi.site",
    "anime": {},
    "episodes": []
  }
}

Important response fields

Field Meaning
source Shows whether the API used anikotoapi.site or slow-anikoto-fallback.
series_id The internal Anikoto ID extracted from the watch page.
anime Anime metadata such as title, slug, poster, status, year, and total episodes.
episodes Array of episode objects.
episode_embed_id The ID used to build SupaPlay player iframe URLs.
embed_url.sub Subbed SupaPlay iframe URL.
embed_url.dub Dubbed SupaPlay iframe URL.
watch Your public Animapo watch-page URL for that episode.
